# 3.2.1 — Document verified movement and resize behavior

## Goal
Update the README and ADR-0001 to describe Task 3.1.1's implemented movement and resize behavior, while separating automated coverage from the limited live Lua-dispatch pair test and making no live claims for plain dispatch or resize mode.

## Source findings and documentation limits
- `planning/STATE_3.md` reports Task 3.1.1 complete, with targeted validation and `make test` passed. Automated tests cover plain/Lua dispatch selection, pair transformations, boundaries/fallbacks, key aliases, manual split bindings, and resize mappings.
- The authorized live test used disposable windows on Hyprland 0.56.2 and directly verified all four Lua-dispatch cross-axis pair transformations, focus identity, and requested-side placement. It did not deploy/reload this project's bindings.
- Plain-mode dispatch and same-axis/non-pair behavior were not live-tested. Resize mode was not live-tested in either mode; its mappings and exits are covered by automated tests only. Do not describe these as live-verified.
- Implementation recognizes a clear pair conservatively (exactly two mapped, visible, ungrouped, non-floating tiled clients with unambiguous perpendicular geometry). Cross-axis moves toggle the pair split and ensure the active window ends on the requested side; same-axis and non-pair requests retain their mode-specific fallback.
- H/J/K/L and arrows are aliases for focus, movement, and resize directions. `SUPER+r` enters resize mode with 20-pixel steps and Return/Escape exits in both configurations. The Lua mode uses `hl.define_submap` / `hl.dsp.submap`; tests cover registration, mappings, and exits, but runtime resize is untested.
- `SUPER+b` and `SUPER+v` remain available. Plain config specifies horizontal/vertical toggles; Lua registers both through Omarchy's generic `hl.dsp.layout("togglesplit")` API. Describe this difference rather than implying identical axis-specific dispatch.
- ADR-0001 currently defers plain-config parity. Task 3.1.1 implements plain-path pair behavior under the user-approved extension, but the installed-helper boundary, conservative scope, and lack of universal Sway semantics remain applicable.
