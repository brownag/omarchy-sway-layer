## Notes
Analysis confirmed the current Lua layer uses `hl.unbind` then `o.bind`; installed `o.bind` delegates to `hl.bind`, and Omarchy exposes callback bindings plus `hl.get_active_window()`. Installed tiling bindings use `hl.dsp.group.toggle()` and window movement options `{ into_group = direction }` / `{ out_of_group = true }`; existing `SUPER+G`, `SUPER+ALT+arrows`, and group-cycle bindings must remain. The live target is Hyprland 0.56.2, and a read-only `hyprctl activewindow -j` query exposed `address`, `group`, and `grouped` fields. Keep `config/hypr/binds_sway.conf`, README, research artifacts, and upstream Omarchy files unchanged. Existing worktree artifacts are untracked; do not stage or alter unrelated files. Live deployment/validation is not authorized by Plan 2 approval alone. Baseline `make test` is expected to be blocked if ShellCheck remains unavailable.
