## Notes
- Scope for execution is `README.md` only; this file is the requested planning artifact and no README is written at this stage.
- Supported flags and behavior were checked in `bin/apply-sway-layer`; the CLI uses `user_custom.conf` when present, else `hyprland.conf`, installs both plain and Lua artifacts, and chooses Lua integration when its engine files are detected.
- The Lua template returns a table; the CLI only adds `pcall(require, "sway_bindings")`. The absence of a specified consumer API must be described as a caveat, not as verified active binding integration.
- `--enable-waybar` adds the managed Waybar startup line; it does not disable Quickshell. `--rollback` accepts `latest` or a timestamp.
- `make test` checks static syntax/configuration and may fail early if required tools are unavailable; no live Omarchy test is available or claimed.
